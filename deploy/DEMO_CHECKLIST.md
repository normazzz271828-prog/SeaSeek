# SeaSeek 第二版演示检查

## 演示前

- 提前十分钟打开首页、影像和协同页，执行一张示例检测以预热模型和云端。
- 确认 HTTPS API 地址、Secrets 和服务健康；临时隧道重建后必须核对地址并更新 Secrets。
- 实际使用的手机浏览器打开任务链接，测试摄像头授权；拒绝授权时使用相册上传。
- 准备已下载的标注图片、演示视频及本地端。离线播放明确为备用结果展示，不宣称在线检测。
- 如需重置，确认只有演示任务会被清理；先等视频结束，再输入私密管理口令并确认重置。

## 八步演练

1. 电脑载入近海演示任务，复制影像页任务链接。
2. 手机打开链接，核对任务短编号一致，拍照或上传授权船舶素材。
3. 手机提交分析，等待真实增强与船舶检测完成。
4. 电脑打开同一任务并刷新，查看检测结果，确认目标。
5. 填写标题和人工经纬度，生成线索；演示海域位置标明为模拟。
6. 地图查看线索，打开处置页，填写演示负责人并更新为处理中。
7. 手机打开指定线索链接，填写文字反馈并更新为已完成。
8. 电脑刷新，检查反馈和状态，导出任务报告。

## 验收目标与记录

在实际比赛手机与笔记本上连续两次完成八步，每轮 ≤5 分钟、单步最长等待 ≤20 秒；零未捕获异常、零白屏、零“准备中”、页面无横向溢出。记录网络、设备型号、每步耗时。自动化手机尺寸模拟不能替代实际手机验收。

若一项超标，记录原因并修复或缩减素材后重测；不得将“代码已推送”或“浏览器模拟通过”写成实机验收通过。

演示后管理者清理指定演示任务；性能探针和其他任务不由重置接口批量删除。
## 第二版稳定性检查

- 在任务总览的管理与维护中查看容量，必要时先导出报告与媒体，再预览选定任务的清理范围并确认；不要现场手改数据库。
- 管理口令只在管理操作时输入，不放进普通云端自动请求或分享链接。
- 分析额度耗尽后，文字反馈和报告仍可使用；按错误提示的等待时间恢复分析。新会话不是稳定身份。
- 失败/取消视频文件由工作线程回收；旧失败目录可按任务清理。成功视频和实拍素材不会由该入口删除。
- 删除记录会让 SQLite 页面可复用，不立即缩小数据库文件。需要归还文件空间时，停止 SeaSeek API、备份数据库后再运行 `tools/compact_media.py`，执行前阅读其参数，不影响拾光服务。
- 视频演示默认每两秒抽样一帧，可提高频率但会增加等待；不要把抽样帧数量当作船舶总数。
